## 🌟 最新功能優化 (本次更新)

### 1. 簡化出題體驗：全面移除「學科分類與難度設定」
- **極致精簡的錄入介面 (`/add`)**：
  - 移除了過去的「學科分類與難度設定」選填區塊與標籤。
  - 現在錄入介面專注於核心出題要素：**題幹**、**單選/複選題型切換**、**4 個選項 (A/B/C/D)**、**標準答案勾選** 以及 **題目解析（選填）**。
- **題庫查詢與管理 (`/questions`)**：
  - 移除難度與分類篩選器，簡化為以關鍵字題幹搜尋與題型（單選/複選）為主。
  - 題目卡片與編輯視窗全面移除分類與難度標籤，版面更為乾淨清晰。
- **自測刷題與儀表板 (`/practice`, `/`)**：
  - 刷題設定聚焦於題型選擇（全部題型 / 僅單選題 / 僅複選題），無冗餘分類阻礙。
  - 首頁儀表板聚焦於總題數、單選題數、複選題數統計。
- **Google 文件試卷匯出 (`/questions`, `/api/export/docx`)**：
  - 匯出之 .docx 與 Rich Text 排版已去除分類與難度標籤，題目編號後直接緊接題型與題幹，版面簡約專業。

### 2. 題目解析 (選填) 與 Google 文件匯出功能
- **多入口快速匯出**：
  - **題庫查詢頁 (`/questions`)**：頂部「📄 匯出 Google 文件」按鈕，可直接開啟匯出精靈。
  - **首頁儀表板 (`/`)**：Hero 區塊新增「📄 匯出 Google 文件」快捷通道。
- **匯出選項設定 (Export Wizard)**：
  - **自選是否含有解析 (核心功能)**：
    - 🔵 **包含解析與答案（教師解答卷 / 完整複習手冊）**：每題標註標準答案，並附帶詳細題目解析說明。
    - 🟢 **不含解析（附標準答案）**：依您的最新要求，**匯出時保留標準答案，但隱藏詳細題目解析說明**（亦可自行取消勾選答案成為純題目卷）。
  - **自訂文件標題與副標題**：
    - 支援自訂試卷大標題（例如：「高二物理期末模擬卷」）與副標題（考試範圍、備註）。
    - 自動產生試卷頂部考生資訊欄（班級、姓名、座號、得分）與防跨頁跑版分隔線。
- **三種便捷的 Google Docs 匯出與使用途徑**：
  1. 📥 **下載 Google 文件檔案 (.docx)**：
     - 後端使用 `docx` 引擎生成標準格式，已配置 `keepNext` 與 `keepLines` 防斷頁機制，在 Google Docs 開啟時保證排版不跑版。
  2. 📋 **一鍵複製為 Google 文件排版 (Rich Text)**：
     - 點擊「複製為 Google 文件排版」，系統將格式化 HTML 試卷寫入剪貼簿。
     - 使用者直接在 Google Docs 頁面按下 `Ctrl + V` 即可貼上原汁原味的試卷排版。
  3. 🌐 **一鍵開啟 Google 文件新檔**：
     - 提供直接前往 `https://docs.google.com/document/create` 建立空白文件的捷徑按鈕。

## 🛠️ 系統全端技術架構

| 層級 | 採用技術 | 說明 |
| :--- | :--- | :--- |
| **全端框架** | Next.js 14 (App Router) + TypeScript | 現代 React SSR/CSR 架構，兼顧效能與開發體驗 |
| **UI 樣式與圖標** | Tailwind CSS + Lucide React | 美觀精緻的卡片式介面與直覺操作圖示 |
| **資料庫與 ORM** | SQLite (`prisma/dev.db`) + Prisma ORM | 本機檔案型資料庫，開箱即用，免裝外部 DB 伺服器 |
| **文件產生引擎** | `docx` 套件 + Async Clipboard API | 產生原生相容 Google Docs / Word 的文件與富文本剪貼簿 |
| **防重複演算法** | 文字正規化 + Levenshtein 距離 + 字元 Dice + LCS | 毫秒級偵測完全重複與中英文高度相似題型 |

### 方法一：桌面捷徑（最簡單）
直接在您的 Windows 桌面上點擊 **「QuizMaster 題庫系統」** 捷徑圖示，系統會自動在背景啟動服務並為您開啟瀏覽器！

### 方法二：終端機啟動
在專案目錄執行：

```bash
npm run dev
```

開啟瀏覽器前往 [http://localhost:3000](http://localhost:3000)：
- **新增題目**：前往 `/add` 體驗 4 選項錄入、輸入解析（選填）以及打字時的即時防重複提示。
- **題庫查詢與匯出**：前往 `/questions` 點擊「📄 匯出 Google 文件」，自由選擇「包含解析」或「不含解析」匯出試卷。
- **自測刷題**：前往 `/practice` 隨機抽題測驗。
